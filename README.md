Fuel Management System
A web application that lets stranded drivers order fuel online when there is no petrol bunk nearby, and track the delivery live.
The Problem
On highways and in remote areas, running out of fuel can leave people stuck for hours. This project connects those drivers with fuel delivery so help reaches them where they are.
Features
• Online fuel ordering
• Add your current location for delivery
• Live order tracking
• Simple, easy-to-use web interface
Tech Stack
• Frontend: HTML, CSS, JavaScript
• Backend: PHP and Python
• Server and database: XAMPP (Apache and MySQL)
How to Run the Project
1.  Install XAMPP on your computer.
2.  Copy the project folder into the htdocs folder inside your XAMPP directory.
3.  Open the XAMPP Control Panel and start Apache and MySQL.
4.  Open phpMyAdmin in your browser, create a new database, and import the .sql file from the project folder.
5.  Open your browser and go to http://localhost/your-project-folder-name.
